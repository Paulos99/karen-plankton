# Карен Планктон — фанатское PWA для Android-планшета

Некоммерческий фанатский проект для костюмированной вечеринки. Не официальный продукт Nickelodeon.

- Frontend (GitHub Pages): https://paulos99.github.io/karen-plankton/
- Backend: Yandex Cloud Function `karen-api` за API Gateway `karen-gw` (код в `backend/`). Секретов в репозитории нет: код устройства вводится один раз в скрытом меню планшета и хранится только в localStorage.
- Меню: удерживать правый верхний угол 2 секунды. Push-to-talk: удерживать левый нижний угол.

## Эмоции, команды и имя (v1.2)

- Все 20 состояний анимированы (SVG + CSS keyframes, canvas для idle/speaking/listening/thinking/reboot). Переходы ~180 мс.
- LLM возвращает `emotion` (и опционально `emotions` — таймлайн до 3 шт.); во время речи поверх волны показывается мини‑лицо/тон эмоции.
- **Команды** — файл `commands.json`, правится без кода:
  ```json
  {"name":["карен","карэн"],
   "commands":[{"emotion":"love","hold_ms":4000,"phrases":["люблю тебя","обожаю тебя"]}]}
  ```
  Текст приводится к нижнему регистру, без пунктуации, `ё→е`. Фраза срабатывает, если каждое слово фразы — начало какого-то слова реплики (поэтому пишите основы: «гениальн», «умниц»). Порядок важен — первая совпавшая команда побеждает. Эмоция включается мгновенно, затем LLM отвечает с принудительной эмоцией (`forced_emotion`). После правки обновите кэш (поднимите версию в `sw.js`).
- **Имя:** если в фразе есть «Карен» без команды — короткая реакция «внимание».
- **Wake word** (меню → «Слушать имя»): Chrome Android `webkitSpeechRecognition` ru‑RU слушает только имя (распознавание у Google, в SpeechKit ничего не стримится), после «Карен» — запись с VAD до 12 с → обычный ход. Пауза во время речи Карен. По умолчанию выключен; push‑to‑talk остаётся.


## v1.4 — офлайн-распознавание
Коснитесь экрана → Карен показывает эмоцию «Слушает» → скажите «Карен, …». Распознавание на устройстве: vosk-browser 0.0.8 (WASM) + vosk-model-small-ru-0.22 (`vosk/vosk-ru-small.tar.gz`, 46 МБ, кэшируется Service Worker'ом), словарь ограничен фразами из `commands.json` (`grammar`). Ответ — заранее записанные реплики SpeechKit (jane) из `audio/`. Облако не нужно; сервисные настройки — только по адресу `#advanced`.
Команды — в меню (удержать правый верхний угол 2 с) → «Команды».

## v1.5 — загрузка модели, прогресс, установка
- Модель распознавания облегчена до 31 МБ (`vosk/vosk-ru-slim-v1.tar.gz`, сборка: `tools/build_slim_model.py`), качается только по кнопке «Скачать модель распознавания» с прогрессом, докачкой (Range), таймаутами, понятной ошибкой и «Повторить»; хранится в Cache Storage `karen-model-v1` + `navigator.storage.persist()`.
- vosk-browser пропатчен: модель распаковывается только в память (без копии в IndexedDB, которая при каждом запуске добавляла ~90 МБ и падала с «FS error»). Архив обязан содержать записи каталогов — иначе движок не видит файлы.
- Кнопка «Установить на рабочий стол» (`beforeinstallprompt`, иначе инструкция ⋮ → «Установить приложение»).

## v1.6 — новые реплики и сценарии
- Все реплики переписаны (характер: сухой сарказм + скрытая забота), 107 файлов голосом jane. Исходник текста: `tools/lines_v2.py` → `commands.json`, озвучка: `tools/gen_audio.py` (запуск из корня проекта-исходника).
- `{эмоция}` внутри текста — смена лица в этот момент аудио. `follow: {yes,no,none}` — Карен задаёт вопрос, сама слушает ответ «да/нет» и отвечает веткой.
- Сценарии: план захвата мира, секретная формула, фейковая перезагрузка с ошибкой, комплимент-прожарка маркетологам, предсказание, викторина да/нет, сцена ревности, колыбельная (засыпает), фото с комментарием до и после.
